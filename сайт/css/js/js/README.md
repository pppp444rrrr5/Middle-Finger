# ПрактикаGuide

Сайт с инструкциями по учебной практике и системой регистрации/входа.

## Запуск
1. Скачайте папку проекта.
2. Откройте `index.html` в браузере (желательно через локальный сервер, 
   например `python -m http.server` — чтобы избежать ограничений localStorage при `file://`).
3. Зарегистрируйтесь и войдите — данные сохраняются в `localStorage`.

## Структура
- `index.html` — главная с инструкциями
- `register.html` — регистрация
- `login.html` — вход
- `dashboard.html` — личный кабинет (защищён)
- `css/style.css` — стили
- `js/auth.js` — регистрация/вход/выход
- `js/guard.js` — защита страниц

## Важно
Это фронтенд-демо: пароли хранятся в `localStorage` в открытом виде.
Для реального проекта нужен backend (Node.js/PHP/Python) и хеширование паролей (bcrypt).
